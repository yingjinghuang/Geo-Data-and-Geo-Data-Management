Week 3: Vector Data Integration

How can we connect tables and spatial features, then summarize the results?

Week Content

This week uses a Vienna case study to bring together vector boundaries, population tables, and public-facility locations.

  • Python basics and working step by step in Jupyter
  • Attribute joins: match records using a shared district ID
  • Spatial joins: assign points to districts by location
  • Aggregation: count matched points by district using GroupBy

Materials

Lecture slides · PDF Lab notebook · IPYNB District boundaries · GeoJSON Population · CSV Drinking fountains · CSV Public toilets · CSV

Lab

Start with the required Python basics in Section 0. The guided part (Sections 1–5) follows our classroom example with Vienna districts, population, and drinking fountains. Additional maps and charts are optional.

For the independent checkpoint (Section 6), use the public-toilet data to create points, join them to districts, count facilities, and explain your results. Follow the steps in the notebook, one cell at a time.

Lab Checkpoint
