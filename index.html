About the Course

Geodata is not one data type, one representation, or one file format. Real geodata is often multi-source, heterogeneous, and multimodal: it may combine geometry, imagery, coordinates, time, text, trajectories, point clouds, networks, and other attributes.

This course focuses on the data layer behind GIS and spatial analysis: where geographic information comes from, how it is represented, how heterogeneous datasets can be related, how geodata is exchanged, stored and queried, and how enough context can be preserved for trustworthy reuse. Vector and raster are treated as two foundational spatial representation models, not as the complete geodata landscape.

Learning Outcomes

After completing the course, students should be able to:

  1. Identify common geodata sources and modalities and distinguish source, modality, representation, and storage/access.
  2. Inspect unfamiliar geodata by asking about its unit, spatial meaning, time, source, meaning, and missingness.
  3. Reason about vector representation, geometry, CRS, and coordinate transformation.
  4. Reason about raster grids, georeferencing, resolution, extent, and NoData.
  5. Integrate heterogeneous geodata using explicit matching and spatial-correspondence rules.
  6. Explain interoperability and compare physical storage choices using preservation and use-case evidence.
  7. Use relational, SQL, and spatial SQL concepts to organise and query related geodata.
  8. Evaluate metadata, quality evidence, provenance, reproducibility, limitations, and reuse conditions.

Teaching & Learning

Each teaching week follows a consistent rhythm: concept → worked example → notebook walkthrough → guided lab → checkpoint. Python and Jupyter are the main practical environment, but programming is a tool for inspecting and testing GeoData ideas rather than the organising principle of the course.

Scope and expectations. The course is not advanced Python training, desktop GIS software training, remote-sensing analysis, point-cloud processing, database administration, or GeoAI. Students are expected to reason about data structures and decisions, run and modify provided notebooks, inspect outputs, and explain evidence.

Lecture

Geodata sources, representations, relationships, standards, storage, queries, trust, and reuse.

Lab

Guided notebook work focused on inputs, outputs, verification, and interpretation.

Readings

There is no compulsory textbook. Short readings, standards, and official documentation will be provided when they help clarify a weekly topic.
